# Agent OS visual boards

Ces fichiers sont les boards visuels utilisables pour présenter le produit et les importer dans un outil de design.

## Fichiers

- `master-board.svg` : vision produit et boucle de moat
- `product-journey.svg` : parcours complet onboarding → activation
- `architecture-ecosystem.svg` : produit, infrastructure intégrée et écosystème
- les mêmes boards en `.png` sont présents dans `../diagrams/` pour les présentations rapides

## Import

Dans Figma, importer les SVG directement : chaque board reste une composition vectorielle éditable. Dans Miro ou Whimsical, déposer les SVG comme frames de référence, puis convertir les groupes en cartes et connecteurs si l’équipe veut les manipuler nativement.

## Utilisation en atelier

1. Présenter `master-board.svg` pour aligner la vision.
2. Utiliser `product-journey.svg` pour jouer le parcours avec un utilisateur fictif.
3. Utiliser `architecture-ecosystem.svg` pour distinguer ce que l’on intègre de ce que l’on construit.
4. Annoter les hypothèses en jaune, les décisions en bleu et les risques en rouge.
5. Transformer chaque zone non résolue en ticket avec un critère de validation.
