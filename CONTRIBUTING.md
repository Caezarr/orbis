# Contributing to Orbis

Thanks for contributing.

## Workflow

1. Branch from `main`.
2. Keep PRs focused.
3. Run `pnpm lint` (and a local `pnpm build` when you touch routing or APIs) before opening a PR.
4. Open a PR against `main` with a short why + what.

## Conventions

- TypeScript / Next.js App Router
- Prefer small, logical commits
- Never commit secrets — keep credentials out of `data/` dumps and chat logs
